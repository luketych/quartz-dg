# styles.css

This file defines the styling for the Monster Canvas extension's webview interface, establishing the visual appearance and layout of all UI components.

## Key Styling Areas:

### Layout Structure
- Implements a responsive layout with a collapsible sidebar and main content area
- Provides smooth transitions for sidebar expansion and collapse
- Establishes the canvas container dimensions and positioning
- Creates a sticky controls section at the bottom of the sidebar

### Component Styling
- Defines the appearance of the character and shape palettes
- Styles the file explorer tree view with appropriate indentation and icons
- Implements button styling with consistent colors and dimensions
- Creates visual feedback for selected and active elements

### Interactive Elements
- Provides hover and active states for clickable elements
- Implements visual indicators for dragging operations
- Styles selected items with distinctive borders and backgrounds
- Creates visual feedback for different interaction modes

### File Explorer Visualization
- Styles the file tree with appropriate indentation and hierarchy
- Differentiates between files and folders with icons and colors
- Implements visual indicators for used files (those already on the canvas)
- Creates toggle controls for expanding and collapsing folders

### Visual Theme
- Establishes a consistent color scheme throughout the interface
- Uses appropriate typography for readability and visual hierarchy
- Implements subtle shadows and borders for depth and separation
- Ensures good contrast for text and interactive elements

This stylesheet creates a cohesive and intuitive visual design for the Monster Canvas extension, enhancing usability through consistent styling and clear visual feedback for user interactions.

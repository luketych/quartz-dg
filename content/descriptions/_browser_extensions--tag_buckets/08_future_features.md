# Future Features - URL Tagger Extension

## 🌱 Tag Enhancements
- ✅ Autocomplete suggestions based on global tag pool
- ✅ Tag aliasing or nested categories (e.g. "AI" → "ML")
- ✅ User-defined tag colors or styles
- ✅ Tag count and frequency analytics

## 🧠 Smart Metadata
- ✅ Auto-fetch Open Graph metadata (title, description, image)
- ✅ Extract readable text snippet or summary
- ✅ Store word count or read time

## 🖊️ Notes and Annotations
- ✅ Rich-text or markdown-compatible note field per URL
- ✅ Inline quote saving from web pages
- ✅ Timestamped highlights with anchor support (like Hypothes.is)

## 📎 Organization & Search
- ✅ Searchable tag + URL interface in popup
- ✅ Sort/filter URLs by tag, domain, date
- ✅ Saved tag filters or groups ("tag sets")
- ✅ Favorite/pin URLs

## 🌐 Integration
- ✅ Obsidian plugin to sync or import tags
- ✅ Markdown/CSV export templates
- ✅ REST API for external access to tag data
- ✅ Sync to cloud services (e.g. Google Drive, GitHub Gist)

## 💻 UI/UX
- ✅ Drag-and-drop tags to reorder
- ✅ Dark mode
- ✅ Configurable banner position (top, bottom, corner)
- ✅ Config panel for user preferences

## 🔐 Security & Sync
- ✅ Optional sync with `chrome.storage.sync` or private server
- ✅ Encrypted local storage
- ✅ Backup/restore system with versioning

## 📦 Dev & Ops
- ✅ Unit tests for storage and merge logic
- ✅ Linting and CI/CD setup
- ✅ Feature flag support for experimental features

## 🤖 AI Features (Future)
- ✅ AI-generated tags from content/context
- ✅ GPT-based tag clustering
- ✅ Auto-suggest related links based on existing tags

## 📱 Multi-Device Support
- ✅ Mobile browser support (Firefox for Android, Kiwi, etc.)
- ✅ Companion mobile app for tagging/bookmarking on-the-go

## 🧪 Experimental Ideas
- ✅ Timeline view of tagged URLs
- ✅ Graph visualization of tag-URL relationships
- ✅ Tag decay (aging out irrelevant tags)
- ✅ Gamified tagging (XP system, streaks, badges)
